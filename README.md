# Funngro Website Revamp Concept

A modern, responsive 2-page redesign concept for Funngro, created to showcase web development and SEO capabilities.

## 🌐 Live Website
* Deployed Site: [https://vinitaaayadav.github.io/funngro-revamp2/](https://vinitaaayadav.github.io/funngro-revamp2/)

## ✨ Key Features
* 2-Page Structure: Dedicated landing pages for Teens/Students and Companies/Employers.
* SEO Friendly: Includes structured meta tags, semantic HTML headers, and clean page hierarchy.
* Mobile Responsive: Built using a mobile-first CSS Grid and Flexbox architecture.
* Direct Contact Footer: Integrated mailto: and tel: links for easy user interaction.

## 🛠️ Tech Stack
* Markup: HTML5
* Styling: CSS3 (Variables, Flexbox, CSS Grid)
* Hosting: GitHub Pages
